Hami حامي

Check a link before you pay

Hami opens the page in a safe browser, reads what it asks you to do with money, and tells you if it looks like a scam, with the evidence. Built for task and deposit scams targeting the UAE.

Try an example:

A check takes 10 to 20 seconds. Only the link and the business name you type are sent to this server. Hami's browser never signs in, submits forms or pays.

Reads the pageDeposit-to-unlock, advance fees, gambling deposits, card requests, in Arabic and English.
Sees through sign-in wallsMatches the software a site delivers against confirmed scams, and reads its own code and routes.
Explains every resultUp to three clues, each citing the sentence, file or confirmed case behind it.
Hami is a working prototype for the ScamShield AI hackathon (AD Police × 42 Abu Dhabi). A result is guidance, not a legal finding. Report scams through official police channels (Abu Dhabi Police Aman 8002626, eCrime). · GitHub · Chrome extension
